==================================================
CART MODELS
==================================================

Create:

apps/cart/

Models:

Cart
- id
- user (OneToOne or appropriate relationship)
- created_at
- updated_at

CartItem
- id
- cart (ForeignKey)
- product_variant (ForeignKey)
- quantity
- created_at
- updated_at

Important relationship:

User
  ↓ 1:1
Cart
  ↓ 1:N
CartItem
  ↓ N:1
ProductVariant
  ↓ N:1
Product

Do NOT store product price permanently in CartItem.

The current ProductVariant/Product price must be used for cart calculations.

Add appropriate constraints.

A user should not have duplicate CartItems for the same ProductVariant.

Use a UniqueConstraint:

cart + product_variant

Quantity must always be greater than 0.

==================================================
ADD TO CART
==================================================

From Product Detail:

User selects:

- Size
- Color
- Quantity

Then clicks:

Add to Cart

Backend must:

1. Require authentication
2. Validate product exists
3. Validate product is active
4. Validate selected variant belongs to that product
5. Validate selected variant exists
6. Validate quantity > 0
7. Check stock
8. Create Cart if necessary
9. Create CartItem or increase existing quantity
10. Never allow quantity above stock
11. Show Django success/error message
12. Redirect appropriately

If item already exists:

increase quantity instead of creating duplicate CartItem.

Example:

Current cart quantity = 2
User adds quantity = 3

New quantity = 5

But if stock = 4:

do NOT allow 5.

Show a clear error message.

REMOVE ITEM
==================================================

- CSRF required
- user can remove only their own cart item

- redirect back to cart

Do NOT use GET for destructive remove actions.

==================================================
CART CALCULATION
==================================================

Use Decimal for money.

Do NOT use float.

For each item:

item_subtotal =
product_variant.product.base_price × quantity

Cart subtotal:

sum(all item subtotals)

Shipping:

৳0

Total:

subtotal + shipping

Keep calculation logic in a reusable model/property/service rather than duplicating calculation in multiple views/templates.
