============================================================
25. ORDER CREATION — CRITICAL
============================================================

Order creation must use:

transaction.atomic()

When creating order:

1. Verify user is authenticated.
2. Verify cart exists.
3. Verify cart is not empty.
4. Lock relevant ProductVariant rows.
5. Re-check stock inside transaction.
6. Calculate product prices from database.
7. Calculate subtotal.
8. Calculate shipping.
9. Calculate total.
10. Create Order.
11. Create OrderItems.
12. Reduce stock.
13. Clear cart.
14. Commit transaction.
15. Send confirmation email after successful transaction.

Never calculate final total from frontend.

Never trust:

frontend price
frontend total
frontend stock
frontend user ID
frontend order number
